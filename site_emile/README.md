# Emile Alexandre portfolio

Double-click `index.html` to open the site. No installation is needed.

## Edit your content

- Experiences, email and links: `js/projects.js`
- Hero, Profile and Contact text: `index.html`
- Colors: the first two blocks in `css/styles.css`
- CV: replace `assets/CV_Emile_Alexandre.pdf` and keep the same file name

## Publish it

1. Create a public GitHub repository (for the address `https://USERNAME.github.io`, name it `USERNAME.github.io`).
2. Upload all these files at the root of the repository.
3. In the repository, go to Settings, then Pages.
4. Choose Deploy from a branch, then `main`, then `/ (root)`, and save.
